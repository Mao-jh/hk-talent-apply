# 优才高才申请·获批画像预审 · 集成支付 AI Skill

> 对话里直接问，出一份带编号依据的风险预审报告。按次付费（¥4.99/次），**无订阅**；
> 已内置**支付宝 AI 收（402）完整支付能力**，装完即用，无需另行安装任何官方支付组件。

## 这是什么

输入拟申请计划（高才A/B/C/优才）与个人画像（学历院校、收入结构与完税、工作年限与雇佣形态、中介参与），返回获批风险报告：风险等级与置信度、逐条风险点（入境处执行口径条目编号+相似获批/拒批案例编号+补强建议）、四类计划申请要求对照、申请必知（A类收入双轨时间算法、B/C类只认本科榜单、优才12准则满足6项≠获批）、拒批与造假后果。

## 怎么用

安装后在对话里直接问，例如：

- 「香港优才申请条件我够不够」
- 「高才A类收入怎么算」
- 「理财收益能算250万收入吗」

流程：Agent 收集必要信息 → 调用后端 → 返回 402 待支付账单 → 内嵌支付流程拉起
**支付宝官方 `alipay-bot` CLI**（npm 包 `@alipay/agent-payment`，首次使用经完整性校验后安装）→
你用支付宝扫码付款 → 服务端验付 → 自动返回报告。支付判定以服务端校验为准，支付由用户本人确认。

## 定价

- **¥4.99 / 次**，按次收费，无订阅、无隐藏费用；与支付宝服务登记价完全一致。

## 你会拿到什么

- `risk_level`：低 / 中 / 高，附置信度
- `hits[]`：逐条风险点，含**编号化依据**（口径条目 TP / TA + 相似案例编号），可信度可核验
- 高才A/B/C/优才四类计划要求对照、申请必知（A类收入双轨算法、B/C类只认本科榜单）与拒批/造假后果
- 固定免责声明：本报告为**风险预审**（顾问位），不构成「必过/必拒」类保证
